   - Interactive mood selector chips (*Feeling Tired, Overwhelmed, Doubting Myself, Wholesome Giggles, Bestie Hug*).

## 🚀 How to Open and Test Locally

You can run and preview this website locally on your computer in multiple easy ways:

### Method 1: Double-Click (Easiest)
1. Open your File Explorer and navigate to this folder.
2. Double-click `index.html`.
3. It will immediately open in your default web browser (Chrome, Edge, Firefox, Safari).

### Method 2: Python Local Server (Recommended for testing)
If you have Python installed, you can start a lightweight local web server:

```powershell
# Open PowerShell in this project folder and run:
python -m http.server 8000
```
Then open your browser and navigate to:
`http://localhost:8000`

### Method 3: VS Code Live Server
1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click `index.html` and choose **"Open with Live Server"**.

## 🌐 How to Publish for Free on GitHub Pages (Public HTTPS Link)

To share this website with Layuuu via a private or public HTTPS link that works on her phone anywhere in the world, use **GitHub Pages**. It is 100% free, fast, and does not require servers or hosting subscriptions.

### Step 1: Create a Free GitHub Account
If you don't already have one, sign up at [github.com](https://github.com).

### Step 2: Create a New Repository
1. Log in to GitHub and click the **`+`** icon in the top right corner, then select **New repository**.
2. Name your repository (e.g., `layuuus-happy-place` or `layuuu`).
3. Set the visibility to **Public** (required for free GitHub Pages).
4. Leave other options unchecked and click **Create repository**.

### Step 3: Upload the 4 Files
You can upload the files directly through GitHub's website:
1. On your new repository page, click **"uploading an existing file"** (or drag and drop).
2. Drag and drop all 4 files:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. In the commit box at the bottom, type `Initial release for Layuuu` and click **Commit changes**.

*Alternative (via Git command line):*
```bash
git init
git add index.html style.css script.js README.md
git commit -m "Initial release for Layuuu"
git branch -M main
git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
git push -u origin main
```

### Step 4: Enable GitHub Pages
1. In your GitHub repository, click on the **Settings** tab (the gear icon near the top).
2. In the left-hand sidebar, click on **Pages** (under the "Code and automation" section).
3. Under **"Build and deployment"** > **Branch**:
   - Change the dropdown from `None` to **`main`**.
   - Keep the folder set to **`/(root)`**.
   - Click **Save**.

### Step 5: Get Your Public HTTPS Link
1. Wait about 60 to 90 seconds while GitHub automatically builds and deploys your website.
2. Refresh the **Settings > Pages** screen.
3. You will see a green banner at the top saying:
   > **"Your site is live at `https://<YOUR-USERNAME>.github.io/<YOUR-REPO-NAME>/`"**
4. Copy that URL and test it on your computer and phone!
